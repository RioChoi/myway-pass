# 내 방식 QR

**내게 편한 화면 설정을 한 번 저장하고, 여러 키오스크에서 다시 사용하는 프로그램입니다.**

예를 들어 작은 글씨가 잘 보이지 않는 사람은 휴대전화에서 ‘큰 글씨’를 선택합니다. 키오스크에서 QR을 읽으면 저장한 설정을 받아 큰 글씨로 보여줍니다. 카페와 병원에서 매번 같은 설정을 고르는 부담을 줄이는 것이 목표입니다.

현재는 **카페 주문과 병원 실손보험 청구를 체험할 수 있는 시제품**입니다. 실제 결제나 보험사 전송은 하지 않습니다.

## 바로 체험하기

코드를 설치하지 않아도 아래 링크에서 사용할 수 있습니다.

| 하고 싶은 일 | 열어 볼 화면 |
|---|---|
| 내게 필요한 화면 설정하기 | [휴대전화용 프로필 화면](https://myway-pass-choi-2026.goldenloom32.chatgpt.site/profile) |
| 음료를 고르고 주문해 보기 | [카페 키오스크](https://myway-pass-choi-2026.goldenloom32.chatgpt.site/cafe) |
| 병원비 보험청구 과정을 따라 해 보기 | [병원 키오스크](https://myway-pass-choi-2026.goldenloom32.chatgpt.site/hospital) |
| 설정에 따른 화면 차이 확인하기 | [비교·검증 화면](https://myway-pass-choi-2026.goldenloom32.chatgpt.site/verification) |
| Android 휴대전화에 설치하기 | [앱 설치 파일 다운로드 · 1.3](https://myway-pass-choi-2026.goldenloom32.chatgpt.site/downloads/myway-pass-debug.apk?v=1.3) |

Android 설치 파일은 시연용입니다. 앱 설치가 번거로우면 위의 휴대전화용 웹 화면을 이용해도 됩니다.

## 이렇게 사용합니다

휴대전화 한 대와 키오스크 화면을 띄울 태블릿 또는 PC가 있으면 체험하기 편합니다.

1. 휴대전화에서 **프로필 화면**을 엽니다.
2. 글씨 크기와 필요한 기능을 직접 고릅니다. 또는 “글씨를 크게 보고 싶어요”처럼 입력하고 **기능 추천받기**를 누릅니다.
3. 추천받은 내용은 본인이 확인하고 고칩니다. **저장하고 QR 보기**를 누르면 내 설정이 담긴 QR이 나타납니다.
4. 다른 기기에서 **카페 또는 병원 키오스크**를 엽니다. 프로필 연결 기능으로 휴대전화의 QR을 읽거나 앱에서 만든 일회용 연결번호를 입력합니다.
5. 설정이 적용된 화면으로 주문이나 보험청구 과정을 진행합니다.

카메라를 사용할 수 없으면 연결번호를 이용하세요. 프로필을 연결하지 않고도 키오스크를 이용할 수 있습니다. 연결번호는 내 화면 설정을 전달하기 위한 번호이며, 본인인증 번호는 아닙니다.

## 어떤 설정을 바꿀 수 있나요?

| 설정 | 화면에서 달라지는 점 |
|---|---|
| 글씨 크기 | 작게·기본·크게·아주 크게 중 선택합니다. |
| 큰 버튼 | 누르는 버튼을 크게 보여줍니다. |
| 높은 대비 | 글자와 배경을 더 뚜렷하게 구분합니다. |
| 쉬운 말 | 안내와 버튼 문구를 더 익숙한 말로 바꿉니다. |
| 소리로 읽기 | 읽기 버튼을 눌러 안내를 듣습니다. 읽는 속도도 고를 수 있습니다. |
| 터치 실수 줄이기 | 누를 수 있는 영역을 넓히고, 연속으로 잘못 누르는 일을 줄이도록 돕습니다. |

여기서 **프로필**은 이름이나 병명이 아니라, ‘큰 글씨·쉬운 말’ 같은 화면 설정 모음을 뜻합니다. 로그인 없이 사용하는 기기에 저장합니다.

## 카페와 병원에서는 무엇을 해 보나요?

**카페**에서는 여러 음료와 간식을 고르고, 온도·크기·추가 옵션을 바꿀 수 있습니다. 장바구니, 매장 이용·포장, 포인트 적립, 결제수단 선택까지 따라 해 봅니다. 포인트 입력에는 안내된 테스트 번호 `01000000000`을 사용하세요. 실제 전화번호나 결제정보는 입력하지 않습니다.

**병원**에서는 가상 환자와 보험계약, 진료 내역을 고르고 청구 사유·서류·동의를 확인합니다. 마지막에는 가상의 청구 결과가 나타납니다. 실제 본인인증, 보험사 전송, 보험금 지급 심사는 하지 않습니다.

## AI는 어디에 쓰이나요?

AI는 두 가지 일을 돕습니다.

- **필요한 기능 추천:** 사용자가 말하거나 쓴 불편 설명을 읽고, 어울리는 접근성 기능을 추천합니다. 추천을 적용할지는 사용자가 결정합니다.
- **화면과 안내 조정:** 저장된 설정과 기기 화면 크기에 맞춰 화면 구성안과 쉬운 안내문을 만듭니다. 프로그램이 결과를 검사한 뒤 정해진 화면 틀로 표시합니다.

AI가 상품 가격이나 결제 결과를 바꾸지는 않습니다. AI가 응답하지 않거나 검사에 통과하지 못하면 준비된 기본 화면을 사용합니다. 불편 설명을 추천에 사용하면 해당 문장이 외부 AI 서비스로 전달된다는 안내가 표시됩니다.

## 프로그램은 어떻게 나뉘어 있나요?

| 구성 | 역할 |
|---|---|
| 휴대전화 앱 | 내 설정을 만들고 저장한 뒤 QR이나 연결번호로 보여줍니다. |
| 키오스크 웹 화면 | 설정을 받아 카페 주문과 병원 보험청구 화면에 적용합니다. |
| 공통 서버 | 연결번호를 관리하고, AI에 요청하고, 주문 금액과 입력 내용을 검사합니다. API 키는 서버에서만 관리합니다. |

현재는 작동 과정을 확인하는 단계입니다. 실제 이용자의 사용 시간이나 실수 횟수가 얼마나 줄어드는지는 아직 측정하지 않았습니다.
