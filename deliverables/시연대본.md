# 내 방식 QR 3분 시연 대본

실제 이용 화면 녹화용 대본입니다. 영상 파일의 대체물로 제출하지 마세요. 현재 자동 브라우저·녹화 도구가 실행 환경 오류로 동작하지 않아 영상은 아직 제작되지 않았습니다.

| 시간 | 화면과 조작 | 설명 |
|---|---|---|
| 0:00–0:20 | 앱 실행, 프로필 기능 목록 | 이름과 장애명 없이 필요한 기능만 저장합니다. |
| 0:20–0:50 | 큰 글씨·터치 어려움을 텍스트로 입력, Jev 추천 요청 | 실제 모델이 필요한 기능을 추천하며 사용자가 확인·수정합니다. |
| 0:50–1:10 | QR 저장, 일회용 연결번호 생성 | QR은 반복 사용하고 번호는 3분 이내 한 번만 사용합니다. |
| 1:10–1:50 | 병원 AI 모드로 연결, 진료과·방문 목적·접수 확인 | 실제 OpenAI 구성안의 출처를 표시합니다. 동작은 프로그램이 고정하며 접수는 사용자가 확정합니다. |
| 1:50–2:10 | 완료 화면의 업무 JSON, 이용 마치기 | 가상 접수 전달 데이터를 생성하고 세션 정보를 지웁니다. |
| 2:10–2:45 | 같은 QR을 카페에 연결, 메뉴·옵션·주문 확인 | 같은 기능 요구를 다른 업무 화면에 재사용합니다. 금액은 서버 카탈로그에서 가져옵니다. |
| 2:45–3:00 | 기본·규칙·AI 모드와 검증 기록 표시 | 실제 API 검사와 아직 수행하지 않은 이용자 연구를 구분합니다. |

실제 API가 실패하면 대체 화면임을 화면과 설명에 그대로 표시합니다. AI가 적용된 것으로 편집하지 않습니다. 음성 입력을 촬영할 경우 인식된 문장을 확인하고 추천을 요청하는 단계까지 보여 주세요.
