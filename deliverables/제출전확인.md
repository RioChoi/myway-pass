# 제출 전 확인

성과보고서 본문은 1쪽이며 원본에 포함된 참가신청서 1쪽이 이어집니다. 별도 참가신청서도 원본대로 제공합니다. 개인정보·동의·서명은 직접 기입해야 합니다.

공식 아이디어 번호는 제공된 후보작 목록에 표시되어 있지 않아 추정하지 않았습니다. 보고서 초안의 확인 필요 문구를 정확한 번호로 교체하거나 주최 측 안내에 따라 정리하세요.

실제 휴대전화·태블릿으로 QR 카메라, 마이크 허용·거부, 음성 읽기, 큰 글씨·고대비 화면, 3분 미사용 초기화를 확인해야 합니다. 현재 자동 브라우저 도구의 실행 환경 오류 때문에 이 단계는 수행하지 못했습니다. Android 기기는 연결되어 있지 않아 APK 실기기 구동을 확인하지 못했습니다.

3분 시연 대본은 준비했지만 화면 녹화 영상은 아직 없습니다. 실제 UI 녹화 영상을 대회 요구 분량인 2~5분으로 제작해야 합니다. 실제 이용자 완료시간·오선택·도움 요청 개선 효과도 아직 측정하지 않았습니다. 자동 테스트 통과를 이용자 검증 성과로 기재하지 마세요.

공개 시연은 누구나 URL로 접속할 수 있습니다. 실제 사람의 의료·결제·신원 정보를 입력하지 않고 가상 데이터만 사용합니다. 전체 AI 호출 기본 한도는 서버별 100회입니다.
