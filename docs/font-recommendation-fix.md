# 글씨 크기 추천 수정 — Android 1.2

## 원인

이전 프로필은 normal·large·xlarge만 지원했고, Jev 질문은 ‘큰 글씨가 필요한가’만 판단했다. 앱은 font 추천이 있으면 항상 large를 적용했다. 따라서 ‘작은 글씨로 보고 싶다’는 요청을 지원할 수 없었다.

‘글씨 크게’는 이전 실제 API 점수가 0.74로 추천 기준 0.75에 미달했다. ‘글씨를 크게 보고 싶다’는 0.83으로 추천됐다. 이는 조사한 문장에서의 결과이며 전체 정확도 수치는 아니다.

## 수정

- Jev의 글씨 질문을 Choice로 변경해 small·normal·large·xlarge·none을 구분한다. 단순히 점수 기준을 낮추거나 키워드로 AI 결과를 대체하지 않는다.
- 앱의 직접 선택·추천 확인·QR·연결번호·키오스크 배율에 작은 글씨를 연결한다. 작게는 키오스크 기본 배율의 0.9배다.
- 사용자가 추천을 확인하고 적용해야 설정이 변경된다. 선택하지 않은 접근성 설정과 음성 속도는 보존한다.
- 추천 요청 중 이전 결과를 숨기고, 새 텍스트·음성 입력을 시작하면 기존 추천을 지운다.
- 새 앱은 recommendationVersion=2를 전송한다. 이전 앱에는 작은·기본·아주 큰 글씨를 ‘큰 글씨 추천’으로 보내지 않고 업데이트 안내를 표시한다.
- 프로필 형식은 기존 값도 계속 읽는다. small 값은 업데이트된 앱·키오스크에서 지원되며 이전 독립 배포본은 읽지 못할 수 있다.

## 확인

- 자동 테스트 19개 통과: 크기별 추천 적용, QR 왕복, 기존 설정 유지, 구형 앱 오적용 차단, 낮은 확신·잘못된 응답 거부 등.
- 실제 Jev로 8개 문장 확인: 작은 글씨 3종, 큰 글씨, 기본 크기, 아주 큰 글씨, 부정·음성 복합 요청, 큰 글씨·터치 복합 요청. 최종 검사에서 8개 모두 기대 결과와 일치했다.
- 실제 모델: jev-1.14.0. 호출은 기존 jev-latest 별칭을 사용한다. 결과는 `deliverables/jev-font-after-fix.json`에 기록한다.
- 기존 키오스크 서버 통합 흐름은 `deliverables/font-fix-integration.json`에 기록한다.
- 실제 Android 기기의 터치·음성·화면은 미검증이다. 브라우저 자동화 도구의 실행 환경 오류도 남아 있어 시각 검증 완료로 보고하지 않는다.

## 사용

Android 1.2 APK 설치 → ‘작은 글씨로 보고 싶다’ 입력 → 기능 추천받기 → ‘글씨 크기: 작게’ 확인 → 선택한 추천 적용 → 저장하고 QR 보기 → 새 QR 또는 새 연결번호로 키오스크 연결.

참고: https://docs.typesafe.ai/primitives/choice
